# 🇳🇬 NaijaGrid: Community Power & Services Hub

> 🚧 **Work in Progress (WIP):** This project is currently under active development. Features and bug fixes are being actively worked on.

**NaijaGrid** is a lightweight, crowd-sourced web application designed to solve two major daily challenges in Nigeria: tracking unpredictable power outages and finding trusted, scam-free local service providers.

---

## 💡 Key Features

* **Crowd-Sourced Power Status:** Real-time user reports on power availability ("Light Dey" 💡 / "Light Don Go" 🌑) by location/zone.
* **Verified Artisans Directory:** A trusted list of local professionals (electricians, plumbers, solar installers, generator mechanics) with active statuses and ratings.
* **Low-Data & Fast:** Optimized for lightweight performance on mobile networks.

---

## 🛠️ Tech Stack

* **Framework:** [Next.js 14 (App Router)](https://nextjs.org/) / [React](https://react.dev/)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **State & APIs:** Next.js Server-side Route Handlers & React Hooks
